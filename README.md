# PSU Summer Practice

## Expense Tracker API. Part 2

Назначенный вариант: вариант 1 - бюджеты по категориям.


## Сценарий проверки модуля

1. Создать категорию через POST /categories.
2. Создать бюджет на эту категорию через POST /budgets.
3. Повторить создание бюджета с тем же categoryId, year и month - должен вернуться 409 Conflict.
4. Создать расход через POST /transactions в пределах бюджета - запись сохранится без предупреждения.
5. Создать или изменить расход так, чтобы сумма расходов за месяц стала больше лимита - запись сохранится, а в ответе появится warning; затем проверить GET /budgets/summary?year=2026&month=6.
